# Arduino Temperature and Humidity Monitor

## Overview
An Arduino Uno project that uses a DHT11 sensor to measure room temperature and humidity, displaying readings on a 16x2 LCD.

## Features
- Displays temperature in Fahrenheit and humidity percentage
- Shows alerts when the temperature is above 80°F or below 60°F
- Handles sensor reading errors

## Hardware
- Arduino Uno
- DHT11 temperature and humidity sensor
- 16x2 LCD1602 display
- Breadboard and jumper wires

## Future Improvements
- Adjustable temperature thresholds
- Temperature and humidity data logging
